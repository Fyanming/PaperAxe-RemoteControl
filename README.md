# 纸伐局域网远控

局域网远控与被控一体桌面软件，基于 WPF（.NET 10）。

## 功能

- 同一程序同时具备远控端与被控端能力
- 被控端监听指定端口，远控端输入局域网 IP 自动连接
- 屏幕画面实时传输，支持画质与帧率调节（最高 60 FPS）
- 控制模式：鼠标键盘远程操作；观看模式：只看不操控
- 双向文件传输，带进度显示
- 远控使用 P2P 直连 TCP 通道，ECDH 密钥协商 + AES-GCM 加密，画面、输入、音频与文件传输全程加密
- 远控窗口实时显示延迟（Ping/Pong 毫秒数），鼠标移动按 60Hz 合并发送以降低操作延迟
- 远控设置面板提供隐私保护与声音传输开关：隐私模式将被控端显示器熄灭（检测到虚拟显示器驱动时配合虚拟屏采集），声音传输开关控制被控端系统声音回传
- 未安装虚拟音频设备时自动降级为直接回传系统默认输出声音，不再静音系统
- 远控连接时被控端右下角弹出系统通知「你已被 xxx 远控」
- 远控时被控端音量归零，断开恢复；自动切换虚拟音频输出设备（VB-CABLE），远控端可听到被控端系统声音
- 开始远控时新建全屏窗口显示画面，四周悬浮深色控制条，按钮清晰可见

## 运行

```bash
dotnet run --project src/ZhifaRemote
```

或先构建：

```bash
dotnet build ZhifaLanRemote.slnx
```

## 音频虚拟设备说明

应用无法凭空安装声卡驱动。软件会自动识别系统里的虚拟输出设备（例如 VB-CABLE 的 "CABLE Input"）。
未安装时，主界面会提供下载引导；安装后远控连接会自动将默认输出切换到虚拟设备并回传声音。

## 目录结构

```text
src/ZhifaRemote/Services/   加密 P2P/TCP 通道、服务端/客户端、屏幕捕获、音频、输入注入、文件传输
src/ZhifaRemote/Themes/     毛玻璃主题与动画资源
src/ZhifaRemote/            MainWindow（工作台）、RemoteWindow（全屏远控窗口）
scripts/                    静态扫描脚本
```
